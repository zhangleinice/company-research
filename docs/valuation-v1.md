# DCF 估值模块 V1

2026-11-18。独立路由 `/companies/:ticker/valuation`，公司列表与收藏列表操作列提供“公司详情 / 估值分析”。保留详情页布局和年度/季度切换，不新增顶部 Tab。

## 已实现

- `packages/shared/src/dcf.ts`：浏览器和 Node 可共同使用的纯 TypeScript 引擎，无框架/数据库依赖。输入金额为百万美元、股数为百万股、引擎比率为小数；UI 百分数显式转换。
- 简单预测：已核准、正的历史 FCFF 按五年增长率推演；没有可靠 FCFF 则禁用。不会将 OCF−CapEx 作为 FCFF，也不会对负基准做机械增长预测。
- 详细预测：五年各自输入收入增长、EBIT 利润率、税率、D&A/收入、CapEx/收入及 ΔNWC 金额。所有参数空白开始，ΔNWC 不补零。
- CAPM 与 WACC，或直接手动输入 WACC；资本权重须合计 100%。没有市场数据源，因此 Rf、Beta、ERP、Kd、权重和税率均标为用户假设，无虚构默认值。
- TV=末年 FCFF×(1+g)/(WACC−g)，再折现五期一次；WACC 必须在 0–100% 且大于 g，g 大于 −100%；末年 FCFF 非正拒绝永续模型。用户另须确认稳定增长/再投资假设，数学上 WACC>g 不代表经济上已稳定。
- EV=五年现值合计+终值现值。股权价值桥接独立要求非经营资产、债务及租赁索偿、其他索偿、估值用稀释股数。关键字段空缺时允许展示 EV，但股权/每股值不强算；非正股权不输出每股价值。
- 现金不会自动全部算为非经营资产，账面债务/权益不会自动当作市场资本权重，历史平均稀释股数不会自动当估值股数。优先股、少数股东及其他索偿须显式输入；明确无该项时允许人工填 0。
- 当前股价及安全边际显示 `—`：当前未接入可靠市场报价来源。
- 状态区分缺参数、需核实、模型不适用、参数完整可计算。完整结果仍是用户假设下的估算，不是经审计目标价。

## 历史基准与缓存

`apps/api/src/modules/valuation/baseline.ts` 复用现有 CompanyFacts 标准化器提供的年度锚点，按 Submissions 最新 10-K/10-Q 锁定报告期：最新完整年度直接作为 TTM，否则 FY+本期YTD−上年可比YTD；同一 concept、USD、本期和去年 YTD 同申报，使用真实财务日期，并允许 52/53 周同期间长度差异。每项保存期间、提交日、concept、accn 与 SEC 链接；缺端点保留 null，不回退旧期冒充最新。

CapEx V1 保留已验证现金 PP&E 标签，不自动纳入未经生产批准的 ProductiveAssets。EBIT 展示为营业利润代理，尚未调整非经营项目。简化历史 FCFF 函数已实现，必须同时满足利息包含在 OCF、资本化/非现金项目已复核、税盾已复核及有效税率/利息输入；本次真实公司未满足，因此输出 null。不会仅凭会计 ETR 自动批准利息税盾。

接口：

- `GET /api/companies/:ticker/valuation`：CIK 缓存读取；缺缓存时只获取单家公司 SEC CompanyFacts/Submissions。
- `POST /api/companies/:ticker/valuation/refresh`：用户点击“仅刷新SEC估值基准”后显式刷新，不涉及任何 AI 或完整公司更新。

增量迁移 `202611180001_valuation` 仅新增 `valuation_cache`（CIK + JSONB）。事务级 advisory lock 防止并发首次重复导入；刷新失败回滚并保留旧缓存。无自动后台批量获取，不使用临时研究文件作为运行时 fallback。缓存时间显示在页面，后续打开读取缓存；获取更新报告期需要显式刷新。

金融类 SIC 60–67 及缺少可确认 SIC 的公司不适用普通 FCFF；未实现银行、保险等专用估值。对工业公司附带金融业务、租赁和特殊融资的适用性仍需使用者研究，不能把 SIC 检查当成完整业务判断。

## 剩余限制

- 暂无历史 FCFF 的人工审批持久化流程；三家公司简单预测按要求保持禁用。详细模式可通过明确假设计算，但是否具有投资意义仍需研究。
- 不自动认定超额现金、可使用税盾、租赁、少数股东和稀释基础，不提供市场参数及股价伪默认。
- 原公司详情结构保持不变，含原内嵌估值待开发占位；本次实现的是独立估值页面，入口在公司/收藏列表操作列。
- 当前预测参数只在页面状态中编辑，不保存情景、生成研究评级或交易建议；未开发无关功能。
