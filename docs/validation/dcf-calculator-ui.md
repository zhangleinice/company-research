# DCF公式计算器改版验收

保留 `/companies/:ticker/valuation`，将原复杂工作台替换为历史现金流、估值假设、DCF公式及每股结果。默认只显示增长率5%、WACC10%、永续增长率3%三个可编辑演示假设，以及必要的研究性FCFF补充入口。均明确标为初始情景假设，不是SEC事实。

- 仅保留一张五行预测结果表；移除五年经营参数输入表、SEC来源表、大型警告框和旧股权桥接编辑表。旧EquityBridgeEditor组件已删除。
- “估值调整”“数据来源”默认折叠。桥接按原验证器计算，金额与股数统一为百万单位；零值仍须明确输入和确认，重大未决事项仍阻止股权及每股结果。
- 使用新的只读 `GET /api/companies/:ticker/valuation/references` 读取已有年度/季度缓存中的现金、债务和股数及相关来源。该接口不获取SEC、不触发AI、不修改数据库。旧估值TTM接口及缓存机制不变。
- 债务账面值及历史股数可自动提供估值近似；现金只作参考，不自动全部加回。其他必要索偿没有默认0。
- 纯TypeScript引擎保留原DCF、WACC、终值和股权公式。仅为简单模式增加显式的研究性FCFF基准：正值、有依据、人工确认三者缺一不可，且不将其标记成已核准历史FCFF。已有核准基准仍可使用，也可切换到明确的研究性调整。

## 验证

`npm run typecheck`、`npm run lint`、`npm test`、`npm run build`全部通过。后端214通过、5项环境测试跳过；前端50通过。Vite仍有原有大包体积提示，构建成功。

Computer Use返回“browser access host is unavailable”；改用本机独立无头Chrome会话，加载真实React页面并完成截图与交互检查。使用KO此前SEC缓存作为离线API夹具，不连接生产数据库，不请求SEC或AI。

浏览器检查：

- 默认只有一张结果表，无Alert，两个详情区默认关闭。
- 实际缓存FCF：16,227−1,945=14,282百万美元。
- 未提供FCFF调整时不产生FCFF预测；未确认完整桥接时，每股值为空。
- 明确输入研究性FCFF 15,459.33及调整依据，预测期增长6%、WACC10%、永续增长3%后，实时得到EV 258,276.92百万美元。
- 使用此前条件性桥接：资产31,395、债务41,619、其他索偿9,861、股数4,314，计算得到股权238,191.92百万美元、每股55.21美元。这仅用于验证当前计算器交互，不是此前三情景的替换或新的KO估值结论。
- 改变增长率会重算；WACC≤永续增长率时拦截；填入重大未决事项时每股值恢复为空，清除后恢复条件性结果。
- 1365px桌面及390px手机宽度无横向溢出，无捕获的浏览器运行异常。
