# Management & Risks 四方向摘要

## 生成与来源

新摘要使用 `management-insights-v3`，按以下顺序生成：

1. 经营表现与变化原因
2. 资金使用与重大决策
3. 未来经营重点与趋势
4. 重大风险

继续复用现有 groups/findings/evidence JSON、模型配置、SDK、分块汇总、租约任务和 PostgreSQL 持久化。没有新增数据库字段或迁移。Business 的 Prompt 和版本保持原样。

Prompt 强调管理层实际披露的原因、决策背景及影响，避免机械重复财务数字和业务介绍；不编造 EPS 贡献、资金用途、增长预测或风险概率。允许空栏目，不强求各类交易或风险都存在。管理层计划和预期须标识为管理层观点。

Schema 校验固定四栏与顺序、中文、最多五条要点、逐字引用和来源段落。前三栏仅接受 Item 7；风险每条至少引用一段 Item 1A，可附 Item 7 说明已发生影响。这些程序校验确保引用匹配与来源范围，语义归纳质量仍取决于生成结果；本次未调用模型验证真实输出。

## 缓存兼容

被动读取先查新版本，没有时回退 `sec-research-v2`。非强制生成同样复用旧申报缓存；初始化检查同时认可新旧管理层版本，避免版本变化触发自动重生成。只有现有明确手动更新/强制重新生成操作才替换展示为新版结果。新版本使用独立缓存唯一键，不覆盖旧版记录。

前端四个标题固定。旧版“经营表现及原因”“未来经营重点”“主要风险”分别映射对应新标题，“资本开支”和“现金流与融资”依原次序并入“资金使用与重大决策”。原文要点、事实/观点类型及引用不改写，不假装旧摘要已完成新的内容归纳。

常规事实不重复显示类型标签；管理层观点、分析判断保留简短标识。章节引用和悬停可见的 paragraphId/原文片段保留，SEC 年报链接仍位于模块顶部。没有新增图表、指标或财务数据处理。
